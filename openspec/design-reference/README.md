# 设计参考文档

本目录包含 AetherMail 项目的设计规范和模式，供开发时参考。

## 文档索引

| 文档 | 描述 |
|------|------|
| [colors.md](./colors.md) | 颜色系统（背景、文字、边框、强调色、功能色） |
| [effects.md](./effects.md) | 视觉效果（Glass 效果、动画系统） |
| [layout-patterns.md](./layout-patterns.md) | 布局模式（三栏布局、设置页布局） |
| [component-patterns.md](./component-patterns.md) | 组件模式（Modal、卡片列表、表单） |

## 使用方式

1. 开发新功能前，先查阅相关设计规范
2. 保持与现有设计风格一致
3. 如需新增设计模式，更新对应文档

## 设计原则

- **深色主题** - 所有颜色基于深色背景设计
- **Glass 效果** - 使用毛玻璃效果增加层次感
- **微妙动画** - 过渡动画简洁不张扬
- **一致性** - 复用现有样式变量和组件模式
