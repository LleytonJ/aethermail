## Context

aethermail 是一个基于 Tauri + Vue 3 的邮件客户端，使用 TipTap 作为富文本编辑器。当前 RichTextEditor 组件支持基础格式（加粗、斜体、列表、链接、图片），但缺少文字颜色功能。

**技术约束**:
- TipTap v3.22.4 (最新版本)
- Vue 3 Composition API
- 内联样式渲染（邮件客户端兼容性）
- 需与现有 StarterKit 扩展兼容

## Goals / Non-Goals

**Goals:**
- 用户可设置选中文本的颜色
- 提供预设颜色快速选择
- 支持自定义颜色输入
- 支持清除颜色格式
- 颜色以内联样式保存，邮件发送后保持显示

**Non-Goals:**
- 背景颜色（Highlight）功能（可在后续迭代中添加）
- 渐变色文字
- 颜色历史记录
- 复杂的颜色主题预设

## Decisions

### 决策 1: 使用官方 @tiptap/extension-color 扩展

**理由**:
- 官方维护，API 稳定，TypeScript 类型完整
- 与 TipTap 生态系统无缝集成
- 实现成本低，只需安装配置即可使用

**备选方案**:
- 自定义 Mark 扩展: 更灵活但维护成本高，当前需求简单，官方扩展足够
- Highlight 扩展: 只支持背景色，不符合需求

### 决策 2: 颜色选择器 UI 使用下拉面板

**理由**:
- 与现有工具栏按钮风格一致
- 预设颜色 + 自定义颜色选择器组合
- 不需要额外 UI 库依赖，使用原生 HTML input[type="color"]

**交互设计**:
```
┌─────────────────────────────────────────┐
│ 工具栏: [B][I][•][1.][🔗][📷] [🎨]      │
│                                         │
│ 点击 🎨 后弹出:                          │
│ ┌──────────────────┐                    │
│ │ ■ 红  ■ 蓝  ■ 绿 │  <- 预设颜色        │
│ │ ■ 紫  ■ 橙  ■ 黛 │                    │
│ │ ──────────────── │                    │
│ │ [清除颜色]        │                    │
│ │ [自定义...] □    │  <- 颜色选择器      │
│ └──────────────────┘                    │
└─────────────────────────────────────────┘
```

### 决策 3: 预设颜色方案

**邮件场景常用颜色**:
```javascript
const presetColors = [
  '#FF0000', // 红色 - 强调/警告
  '#0000FF', // 蓝色 - 链接风格
  '#008000', // 绿色 - 正向信息
  '#800080', // 紫色 - 特殊标记
  '#FFA500', // 橙色 - 提醒
  '#4B0082', // 黛色 - 专业感
]
```

## Risks / Trade-offs

| 风险 | 缓解措施 |
|------|---------|
| TextStyle 扩展加载顺序错误导致颜色功能失效 | 文档明确顺序：TextStyle 必须在 Color 之前 |
| 颜色选择器在小屏幕上体验不佳 | 下拉面板位置自适应，靠近按钮 |
| 内联样式在某些邮件客户端被剥离 | 选择邮件兼容性好的颜色格式（hex），避免 rgba |
| 与现有 Mark 扩展（Link）样式冲突 | 检测当前激活的 Mark，优先应用颜色 |
