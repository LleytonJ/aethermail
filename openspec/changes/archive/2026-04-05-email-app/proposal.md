# AetherMail 项目提案

## 项目概述

**项目名称：** AetherMail

**愿景：** 为个人用户打造的现代化、轻量级桌面邮箱客户端

**核心目标：** 7 天内完成最小可用版本 (MVP)，实现 POP3 邮箱的收件和查看功能

---

## 问题陈述

### 现状

现有桌面邮箱客户端存在以下问题：

| 客户端 | 问题 |
|-------|------|
| Outlook | 过于臃肿，企业功能复杂，启动慢 |
| Foxmail | 界面老旧，体验停留在 10 年前 |
| Thunderbird | 配置复杂，对新手不友好 |
| 网页邮箱 | 依赖浏览器，多账户切换不便 |

### 用户痛点

- 想要一个**简洁快速**的桌面邮箱工具
- 只需要**基础的收发和查看**功能
- 偏好**现代化 UI 设计**，类似 AetherMail 风格
- 使用**个人邮箱**为主，不需要企业功能

---

## 解决方案

### MVP 范围 (v0.1)

**包含功能：**
- ✅ POP3 协议收件
- ✅ 邮件列表展示
- ✅ 邮件阅读（HTML + 纯文本）
- ✅ 单个账户管理
- ✅ 基础附件显示
- ✅ 本地 SQLite 存储

**不包含功能：**
- ❌ SMTP 发件（v0.2）
- ❌ 回复/转发（v0.2）
- ❌ 多账户支持（v0.2）
- ❌ 搜索功能（v0.3）
- ❌ 键盘快捷键（v0.3）
- ❌ 主题切换（v0.3）
- ❌ 会话线程（v0.4）

### 技术选型

| 层级 | 技术 | 理由 |
|-----|------|------|
| 框架 | Tauri v2 | 轻量、安全、跨平台 |
| 前端 | Vue 3 + TypeScript | 开发效率高，用户熟悉 |
| 样式 | Tailwind CSS v4 | 快速构建现代 UI |
| 状态 | Pinia | Vue 官方推荐 |
| 后端 | Rust | 性能优秀，类型安全 |
| 数据库 | SQLite | 本地存储，零配置 |
| POP3 | async-imap / 自研 | 成熟 crate |
| SMTP | lettre | v0.11+ (后续版本) |

## 技术架构

### 三层架构

```
┌─────────────────────────────────────────┐
│     UI Layer (Vue 3 + Tailwind)         │
│  ┌─────────┐ ┌─────────┐ ┌───────────┐ │
│  │ Sidebar │ │  List   │ │  Reading  │ │
│  └───────── └─────────┘ ───────────┘ │
└─────────────────────────────────────────┘
                    │ IPC
┌─────────────────────────────────────────┐
│     Service Layer (TypeScript)          │
│  ┌─────────────────────────────────┐    │
│  │   EmailProvider (POP3 实现)      │    │
│  └─────────────────────────────────┘    │
└─────────────────────────────────────────┘
                    │ IPC
┌─────────────────────────────────────────┐
│     Backend Layer (Rust + Tauri)        │
│  ┌────────┐ ┌────────┐ ┌────────────┐  │
│  │ POP3   │ │ SQLite │ │  System    │  │
│  │ Client │ │  DB    │ │  Tray      │  │
│  └────────┘ └────────┘ └────────────┘  │
└─────────────────────────────────────────┘
```

### 核心数据流

```
1. 用户添加账户 → 存储配置到 SQLite
2. 定时同步 (5 分钟) → POP3 LIST → RETR → 存储邮件
3. 用户点击文件夹 → 从数据库加载邮件列表
4. 用户点击邮件 → 从数据库加载邮件内容 → 渲染
```

## 成功标准

### MVP 验收标准 (v0.1)

- [ ] 能添加 POP3 邮箱账户
- [ ] 能同步邮件到本地（至少 100 封）
- [ ] 邮件列表正确显示（发件人、主题、时间）
- [ ] 邮件内容正确渲染（HTML + 纯文本）
- [ ] 附件列表显示（不含下载）
- [ ] 无严重安全漏洞（XSS、密码明文存储）
- [ ] 打包为可执行文件

### 非功能性要求

| 指标 | 目标 |
|-----|------|
| 首次启动时间 | < 3 秒 |
| 邮件列表加载 | < 500ms (1000 封) |
| 内存占用 | < 200MB |
| 安装包大小 | < 50MB |
| 支持平台 | Windows 10+ |

## 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|-----|------|------|---------|
| POP3 协议实现复杂 | 中 | 高 | 使用成熟 crate (async-imap) |
| 邮件编码问题 (中文/日文) | 高 | 中 | 使用 mail-parser 自动处理 |
| SSL/TLS 连接兼容性问题 | 中 | 高 | 提前测试主流邮箱服务 |
| HTML 邮件 XSS 风险 | 高 | 高 | DOMPurify + iframe 沙盒 |
| 大附件导致内存溢出 | 中 | 中 | 限制大小，流式处理 |
| Gmail OAuth2 认证复杂 | 中 | 中 | MVP 仅支持标准 POP3/密码 |

### Gmail 特别说明

Gmail 默认关闭 POP3，需要用户手动开启：
1. 设置 → 转发和 POP/IMAP → 启用 POP3
2. 使用应用专用密码（如果开启 2FA）
